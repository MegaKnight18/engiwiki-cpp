# Lab3 | Системы счисления

### Реализуйте программу в соответствии с требованиями

> **Указание:** В задаче запрещено использовать сторонние функции за исключением функций ввода/вывода (`scanf` и `printf`).

1. На вход программе подается целое число **N** (в диапазоне от -65535 до 65535), считываемое в переменную типа `long long`, и число **B** из множества {2, 10} — система счисления, в которой записано N. 

   Если N задано в десятичной системе (B = 10), программа переводит его в двоичную систему. Если в двоичной (B = 2) — переводит в десятичную. Результат выводится на экран. 
   
   Программа должна вывести строку ERROR в следующих случаях:
   * Число N вышло за рамки указанного диапазона [-65535; 65535].
   * Число N содержит цифры, недопустимые для системы счисления B (например, цифры 2-9 при B = 2).

   > **Указание по знаку:** Во входных и выходных данных в двоичной системе счисления перед положительным числом (или нулем) всегда ставится цифра 0, перед отрицательным — цифра 1.

    Пример:
    | Входные данные | Выходные данные | Примечание |
    | :--- | :--- | :--- |
    | 86 10 | 01010110 | *86 в двоичной системе, 0 в начале — знак плюс* |
    | -86 10 | 10101010 | *86 в дополнительном коде, 1 в начале — знак минус* |
    | 01010110 2 | 86 | *Перевод двоичного положительного числа в десятичную* |
    | 10101010 2 | -86 | *Перевод двоичного отрицательного числа в десятичную* |
    | 147 2 | ERROR | *Ошибка: цифры 4 и 7 не могут быть записаны в двоичной системе* |
    | 100000 10 | ERROR | *Ошибка: число вышло за рамки допустимого диапазона* |
